To capture your own (PNG, into this folder). The portal shots need a member of the `students` or `faculty` group:

```bash
pip install playwright && playwright install chromium
SITE_USER_EMAIL=student@example.com SITE_USER_PASSWORD=... \
  BASE_URL=http://localhost:5001 python3 ../../scripts/capture-screenshots.py ../shots.json .
```
