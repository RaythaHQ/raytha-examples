# Brief: Ossingford Public Library — a public library website (fictional)
Persona: Ossingford Public Library (fictional), a county library system with four branches (Central Library on Kettle Square, Millrace, North Quarry, Ferrin Heights) and a Bookmobile, all in an invented county. The library's web team and branch staff run the site. The same build fits a library's own team or county IT, or an agency building sites for libraries.
Design: "card catalog" — warm card stock with ruled lines, index cards with a red top rule, brass label holders for the menu, manila date-due slips with red rubber stamps, and library green shelves with new arrivals drawn as book spines. Source Serif 4 for headings, Public Sans for text, Courier Prime for call numbers, hours and stamps. No wide display fonts.
IA: home (today's hours for every branch, chosen on the server by weekday; new-arrivals shelf; this week's programs; reading lists; digital resources; news); /branches (weekly hours, features, status); /programs (weekly planner Monday to Sunday, server-side audience filter); /new (new arrivals with shelf filter, title pages as catalog cards with availability and holds); /lists; /resources (A–Z; public, cardholder and staff audiences); /news; /about; /get-a-card (in person only); /my-library (members-only, cardholders); /staff-room (members-only, staff); /search.
Members: user groups `cardholders` and `staff`; gating is server-side in Liquid with CurrentUser.UserGroups. Gated bodies are never sent to the browser.
No payment, registration, hold, sign-up or contact forms. Everything is labeled fictional; phone numbers use 555.
Buyer target: self-hosted CMS for public libraries / open-source .NET CMS for libraries.
Done: raytha check 0 failed, screenshots, walkthrough, rebuildable kit.
