To capture your own (PNG, into this folder). The staff portal shots need a member of the `staff` group:

```bash
pip install playwright && playwright install chromium
SITE_USER_EMAIL=staff@example.com SITE_USER_PASSWORD=... \
  BASE_URL=http://localhost:5001 python3 ../../scripts/capture-screenshots.py ../shots.json .
```
