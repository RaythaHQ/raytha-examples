# June Calloway, Marfa: a website for a solo architect

The website of June Calloway, AIA (fictional), a solo architect in Marfa, Texas building rammed-earth and desert-modern houses, built on Raytha. A dated drawing-set index, field notes, transparent process/fees, current availability and a qualifying start page. Blueprint-styled, first-person, no client portal.

- **Brief:** [brief.md](brief.md)
- **Build time:** under an hour
