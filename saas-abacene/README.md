# Abacene: a SaaS product marketing site

The marketing site for Abacene (fictional), a usage-metering and billing-ledger product for API companies, built on Raytha. Features as a spec sheet, pricing tiers as content, docs with public, customer and beta access levels, a changelog, customer stories, an integrations directory, and a members-only customer and beta hub gated on the server. "Ledger tape" design — no payment, trial sign-up or contact forms.

- **Brief:** [brief.md](brief.md)
- **Build time:** under an hour
- **Write-up:** [raytha.com/use-cases/abacene-usage-metering](https://raytha.com/use-cases/abacene-usage-metering)

## Rebuild

```bash
RAYTHA_URL=https://your-site.example RAYTHA_API_KEY=... bash build.sh
```

6 content types (features, pricing plans, release notes, docs, customer stories, integrations), 2 user groups (`customers`, `beta`), site pages (home, security, about, customer and beta hub, search), menus. Server-rendered Liquid only.

## Members-only areas

- Docs have an `access` field (`public`, `customers`, `beta`); release notes have an `audience` field (`public`, `beta`).
- Templates read `CurrentUser.UserGroups` on the server and render either the body or a lock panel with a sign-in link. Members of `beta` are also treated as customers; admins see everything.
- `/beta` is the customer and beta hub (template `ab_beta`).
- To try it, create a public user in the admin, add them to `customers` and/or `beta`, and sign in at `/account/login`. There is no registration form on purpose.

## Notes

- Seed art (`seed/art/*.svg`) is generated by `seed/make-art.py`; `build.sh` runs it when the folder is missing.
- Templates write `&#36;` instead of a literal dollar sign before a digit: in Raytha 2.0.1 a child template containing `$1` is read as a regex group when it is merged into the layout.
